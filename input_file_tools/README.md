This directory contains tools and information about how to manipulate input data files and extract information. A sample input data file is provided for each example, drawn from a simulation for a source point at 5 mm from the center of the field of view, in a slice at the center of the axial field of view.

The Geant4 simulation outputs only binary files, so we need to update or create the corresponding header files.

* For CASToR, one needs to determine the number of coincidences recorded in the binary file by running ***cdf_parser.cc***, and then create a header file similar to _test.cdh_ in the [CASToR directory](https://github.com/Recursion-Q19/CASTiR/tree/main/input_file_tools/CASToR), updating the parameter *Number of events*. For this project, we only need to update the parameter _Number of events_ in the sample _test.cdh_ file. However, for a different scanner, for example, you can also update the name of the scanner, set the parameter **Maximum axial difference mm**, or set the parameter for a correction to 1 if that correction is going to be applied. There are programs to parse the LUT file and to combine two binary files into a third file. 

* For STIR, a file for reading the binary data file output by the simulation is provided, along with a file that appends one input file to another. As explained in the [reconstruction](https://github.com/Recursion-Q19/CASTiR/tree/main/reconstruction) directory, the binary list-mode data must first be converted to projection data using lm_to_projdata in STIR. Sample parameter files that are needed for this conversion are provided in this directory.
